# CPI/PPI/PCE replication & nowcasting — stage report

*2026-07-22. Written for a reader new to the project.*

## 1. What this is

This is an open-source system that **reconstructs the official U.S. inflation prints** (CPI, PPI,
and core PCE) from their published components, and the infrastructure to **nowcast** those prints
before they are released. The **replication layer is complete and measured**; the **prediction
layer is designed but not built**. Data policy: public and licensed sources only, we store and
publish **derived indices and methodology only** — no proprietary firm data, no scraped feeds
behind logins.

Two terms used throughout. **NSA / SA** = not-seasonally-adjusted vs seasonally-adjusted.
**MoM** = month-over-month percent change; all targets here are MoM in basis points (bp;
1 bp = 0.01%).

## 2. Methodology

### 2a. Information discipline — no hindsight

Every backtest reads **only what was knowable at the moment of forecast**. This is the single
most important design choice, because inflation data is revised, and a backtest that reads
today's revised values instead of the originally-published ones is silently grading itself on
the answer key.

- **First-release / vintage.** A *vintage* is a value as it stood on a given date; the
  *first-release* value is what was actually printed on release day, before any revision. We
  archive the full vintage history (via ALFRED, the archival companion to FRED) and, together
  with a release-calendar table, enforce that a forecast for month *M* sees only values released
  on or before its forecast time.
- **Why it matters, quantified.** Two exhibits show the size of the hindsight a naïve backtest
  would capture: at the 2023 PCE comprehensive revision, a cross-vintage MoM reads **−6.97%**
  where the true within-vintage first-release value was **+0.145%** — **711 bp** of pure
  look-ahead. And each February the CPI seasonal factors are restated, handing a latest-vintage
  backtest a recurring **~3.5 bp** free edge. Both are removed by construction here.
- **Proxy side.** Alternative-data inputs (retail gasoline, wholesale used-car prices, etc.) get
  the same treatment through **evidence-backed publication rules** — each series is released only
  as of the date it was actually published (e.g. the wholesale used-car index for month *M* is
  withheld until the first week of *M*+1, verified against the publisher's dated archive).

### 2b. NSA doctrine — forecast NSA, convert with the agency's own factors

Seasonal adjustment is a large, avoidable error source. Our first approach — re-estimating
seasonal adjustment ourselves (default X-13ARIMA-SEATS) — left a **72–95 bp/month** gap versus
the BLS-published SA on volatile strata: too large to be useful. It was **retired**. Instead we
forecast in **NSA space** (the NSA index is never revised, so it is clean first-release by
construction) and convert to SA using **BLS's own published seasonal factors**, harvested from
the annual factor files. The SA-conversion overhead of that pathway is **~0.02 bp** at the
stratum level — three-plus orders of magnitude below re-estimation.

### 2c. Aggregation

Aggregate indices are rebuilt with a **price-updated Laspeyres** formula (the BLS convention) on
the published component partition, using the official relative-importance weights. The
**CPI/PPI → PCE bridge** combines component price changes with **BEA expenditure weights** (NIPA
Underlying Detail Table 2.4.5U), and each component's proxy is mapped to BEA's actual source per
the **NIPA Handbook** (chapter 5, Table 5.B — cited mapping, not assumed).

### 2d. Evaluation protocol

Model claims are held to a pre-committed standard: **hypotheses are pre-registered** (written
down before the code), **thresholds are frozen before results are seen**, and the forecasting
backtest is a **purged, embargoed walk-forward** (train only on data separated from the test
month, to prevent overlap leakage) — this is the standard the prediction layer (Session 4) will
be built and judged under. Results are labeled with **three honesty tiers, never blended**:

- **PURE OOS** — zero fitted parameters (the aggregation machinery). Every month is genuine
  out-of-sample because nothing was estimated.
- **QUASI-OOS** — no fitted parameters, but a specification was verified on the same window it is
  scored on; carries a **selection asterisk** until forward data exists.
- **PRISTINE** — data released *after* the analysis date, untouched by any choice. This is the
  only tier that can validate a predictive claim. **It is currently empty.**

## 3. Results (2023-01 → latest release; labels never blended)

### 3a. CPI aggregation machinery — PURE OOS

Reconstructing the official first-release print from first-release components, MoM deviation:

| aggregate | MAE | median | worst month |
|---|--:|--:|--:|
| **headline NSA** | **0.42 bp** | 0.25 | 1.43 (2023-04) |
| **core NSA** | **1.12 bp** | 0.55 | 6.11 (2023-09) |
| headline SA | 3.98 bp | 3.22 | 16.40 (2023-08) |
| core SA | 2.96 bp | 2.67 | 9.27 (2023-10) |

NSA reconstruction sits at the **index-rounding floor** — official indices are published to three
decimals, so ~0.2–0.3 bp of any MoM is pure rounding, and 0.42 bp is within a factor of two of it.
The result holds through the **2026 tariff-era** months (headline NSA ~0.01–0.03 bp). The **SA
figures are larger, and the reason is a vintage artifact, not a machinery error**: older SA
components have been re-seasonally-adjusted several times since first release, so reconstructing
them and comparing to the *first-release* SA print mixes vintages. NSA — which is never revised —
is the clean measure; the SA numbers are shown for completeness with this annotation.

### 3b. CPI/PPI → PCE bridge — QUASI-OOS

The bridge produces a core-PCE MoM estimate on **CPI-release day, ~2 weeks before the official
PCE print**, using only information public by then. Against the first-release core PCE print,
2023-01 → 2026-05:

- **Unbiased:** mean signed error **+0.36 bp** (asterisked — see below).
- **Dispersion:** MAE **7.97 bp**; 10th–90th percentile band **[−11.9, +12.7] bp**.
- **Direction:** boundary hit-rate **39%** on the calls that aren't coin-flips (**COIN-FLIP** = a
  call landing within 1.5 bp of a 0.1%-rounding boundary, where which way it rounds is genuinely
  a toss-up and is reported as such rather than scored).

*The +0.36 bp is selection-asterisked:* the residue specification (below) was audited and one
carry term reversed on this same window, so the bias is **quasi-** not pristine out-of-sample —
only forward prints can confirm it.

**The finding, stated as a finding:** ~**7 bp is the measured floor** for CPI-day core-PCE
precision at component granularity. It is not a bug to be fixed. BEA does not price PCE by simply
re-weighting CPI/PPI; it applies a **commodity-flow reweighting** that makes each PCE component
price a *derivative* of the CPI/PPI inputs, not a copy. So even a bias-free, correctly-weighted
CPI/PPI aggregation diverges from BEA's component prices by ~7 bp per month. A **≤2.5 bp** CPI-day
core-PCE nowcast at this granularity is therefore **not achievable**, and that claim was formally
retired (§3d).

#### Exhibit — what cannot be tracked at CPI-day, and why

*"Residue"* = the components with no adequate CPI/PPI proxy on release day. Three lines carry it:

| residue line | why it is untrackable at CPI-day |
|---|---|
| financial service charges & fees | BEA blends bank-service CPI + brokerage PPI + smoothing; no single proxy tracks it (best correlation ~0.32) |
| financial services furnished without payment | an *imputed* line (value estimated, not transacted) built from Flow-of-Funds data — no market price exists to observe |
| NPISH final consumption | non-profit institutions' output, valued at input cost — again no market price |

Together they are **10.5% of core-PCE weight but only 9.7% of core-PCE MoM variance**. They are
carried at a frozen, rules-based **carry** (currently freeze-at-zero, re-selected each January on
prior-year data). The remaining ~90% of core PCE tracks well and unbiased; isolating the residue
is what keeps the honest number honest rather than letting three unforecastable lines masquerade
as forecast error.

### 3c. Signal inventory for the (unbuilt) prediction layer

Alternative-data signals, admitted or measured for later use, each on the vintage-safe basis:

| signal | relationship to official | status |
|---|---|---|
| retail gasoline (EIA) vs CPI gasoline | **NSA R² = 0.978**, near-unit pass-through | admitted (contemporaneous) |
| wholesale used cars (Manheim) vs CPI used cars | leads by 2 months, **peak R² 0.35** | admitted as a 2-month lead only |
| market rents (Zillow) vs CPI rent / OER | **leading, not contemporaneous** — statistically (unstable same-month fit) and by calendar (the rent read lands *after* the CPI print it would inform) | leading-only |
| drug prices (NADAC) and others | overlap still accumulating | pending |

### 3d. The record of failures

These are results, not footnotes — each established something.

- **Degraded-input PCE gate — FAIL (12.2 bp).** Run before true BEA weights existed, on
  CPI-weight proxies. Established that the weights, not the aggregation, were the problem: proxy
  weights over-counted shelter 3× and near-zero-counted healthcare.
- **Valid PCE gate — FAIL (9.1 bp), bias eliminated.** With true BEA weights the systematic bias
  collapsed **+10.3 → −0.3 bp**; the remaining error is dispersion, attributed component-by-
  component against BEA's own price detail. Established that the bridge is an **unbiased monitor**,
  not a precision instrument.
- **Instrument-B (precision sub-aggregate) — terminated.** A carve-out of only the trackable
  components still could not reach 2.5 bp (7 bp floor). Established §3b's floor as **structural**,
  and formally ended the precision claim.
- **H2 (market rents predict this month's CPI rent) — falsified.** Rents lead by ~a year; the
  signal is real but leading-only.
- **H9b (portfolio-management fees follow an equity-index path) — falsified.** BEA uses a producer
  price index, not an asset path; corrected to the cited PPI source.
- **H9c (a frozen drift beats freeze-at-zero for the imputed carry lines) — falsified
  out-of-sample.** The drift, fit on pre-2023 data, over-corrected once interest rates rose; the
  null (freeze-at-zero) was restored. Established the value of the pre-registration discipline —
  a plausible term was proposed, tested, and rejected on the evidence.

## 4. What is NOT built

- Pre-print CPI/PPI **forecasts** (the actual prediction layer — everything above is replication
  *given* the prints).
- A **PPI final-demand aggregator** (no final-demand weights ingested yet).
- **Forward daily collectors** and a **live intramonth tracking harness**.
- **Pristine forward evaluation** — no post-analysis-date prints have accumulated yet.

No timeline is promised for these.

## 5. Reproducibility

The repository is laid out as: `pipelines/` (one folder per data source, each a frozen
ingestion artifact with a license note), `src/nowcast/` (index math, seasonal factors,
aggregation, the bridge, the two firewalls), `docs/` (per-phase logs and the acceptance /
OOS reports), `tests/` (**106 passing**). The OOS deviation report regenerates from committed
code and the governed local database; every figure in this document traces to a committed
artifact — `docs/oos_report_1.md` (the standing deviation tables), `docs/pce_bridge_acceptance.md`
(the gate history and diagnosis), and `docs/aggregation_error.md` (the machinery floors).
