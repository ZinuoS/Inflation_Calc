# License note — macro_state

**Source:** FRED (Federal Reserve Bank of St. Louis) — DTWEXBGS (broad dollar), DGS2 (2y
Treasury), DCOILWTICO (WTI). Retrieved via the FRED API (`FRED_API_KEY`). Checked 2026-07-22.

government data, public domain). We store only derived monthly relatives as model features; no
redistribution of raw series. Feature input only, never a backtest target.
